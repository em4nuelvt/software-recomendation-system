# Protótipo do Sistema de Recomendação de Tecnologias

Este diretório contém a implementação completa do protótipo desenvolvido no Trabalho de Conclusão de Curso (PFC II - CEFET-MG).

## 🚀 Como Executar

Para executar o sistema completo de recomendação (Etapas 1, 2 e 3):

```bash
# A partir da raiz do repositório:
python run.py

# Ou diretamente dentro de src/:
cd src
python executar_sistema.py
```

Para testar isoladamente apenas o Extrator de Requisitos (Etapa 1):
```bash
cd src
python main.py
```

Consulte o [README principal do projeto](../README.md) na raiz do repositório para o guia completo de instalação, pré-requisitos do Ollama e instruções detalhadas de uso.
